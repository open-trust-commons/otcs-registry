# Names and marks

*Version 0.1 · Status: EXPERIMENTAL*

---

## 1. The two names

| Name | What it refers to |
|---|---|
| **Open Trust Commons** | The public name of the commons — what it *is* |
| **OTCS** — the Open Trust Coordination System | The formal name of the machinery — how it *works* |

**Kinetic Trust Protocol (KTP)** is independently authored by Chris Perkins. This registry **adopts KTP's coordinate vocabulary. It does not own KTP**, and KTP is registered here under the same evidence rules as any other project ([CHARTER.md](CHARTER.md) §11).

## 2. Permitted without asking

- Stating accurately that your project is registered in the Open Trust Commons
- Stating that it implements a named interface at a stated rung of the compatibility ladder
- Stating that it uses OTCS schemas
- Citing and quoting the specifications, under CC BY 4.0

## 3. Not permitted

- Implying endorsement, certification, approval or membership **beyond what your record states**
- Using the name or marks to suggest your project was validated here
- **Claiming a compatibility rung you have not reached** — `CONFORMANCE_TESTED` is unreachable today, because no suites exist
- Using the marks as your own product name
- Using them in any way implying you steward the Commons

## 4. Why this file exists at all

> A registry whose name implied endorsement would become the certification authority [NON-GOALS.md](NON-GOALS.md) forbids.

These naming rules keep *"registered in the Commons"* a statement of fact rather than a badge.
