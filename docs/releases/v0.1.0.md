## Summary

A public list of trust-governance work, written in one shared vocabulary. Each project describes itself; the description is kept, dated and published. Nothing is rated.

This release publishes the whole corpus at once: the governance documents, the coordinate vocabulary, the schemas that check a record, the interfaces where projects hand off to each other, seven registry entries, and the tooling to verify all of it from a clean clone.

## Why this release exists

The problem is stated in one line and has not changed: **people building ways to control what automated software may do use different words for the same idea, and the same word for different ideas.** The work is therefore hard to compare, easy to duplicate, and almost impossible to fit together.

A registry that rated those projects would make the problem worse by adding a scoreboard to a field that already has too many claims. This one records what each project says about itself, dates it, and refuses to grade it.

## Added

- **Governance** — charter, governance process, voting, code of conduct, communications planes, maintainers, contributing, DCO
- **What a record means** — evidence model with seven evidence states and a maturity profile that may not be collapsed to one number, registry policy, owner verification, project lifecycle, identifiers, qualifying projects, Commons stages
- **The vocabulary** — the normative coordinate semantics, plus `LAYERS.md`, a *proposed and unratified* three-layer reorganisation
- **Analysis constraints** — analysis model, analyst disclosure, AI review protocol, algorithm registry, minority reports, owner right of response
- **Refusals** — twenty things this will not become, the badge and claims policy, acceptable use, safety, privacy, trademarks, patents
- **Integrity** — security, incident response, hosting and mirrors, sync policy, federation, Bitcoin anchoring, accessibility, sustainability, pre-mortem
- **Formats** — 9 schemas plus 3 wire schemas, with fixtures
- **Interfaces** — 10 handoff points
- **Registry** — 7 records: 3 real, 4 fictional and marked `example`
- **Tooling** — `validate`, `test`, `ledger:verify`, `coherence`, `build:site`, `roadmap:status`, `anchor`
- **Two standing tests the vocabulary can fail** — `CALIBRATION.md` (Bitcoin) and `profiles/financial-crime` (one real industry)

## Known limitations and non-claims

**This release does not establish any of the following.**

- **Not that any listed project is good, safe, or fit for use.** A listing records a self-description
- **Not that anything here is endorsed.** There is no badge and there will not be one
- **Not consensus.** One person wrote these documents and one person ratified them
- **Not that the vocabulary is neutral.** The same person wrote the registry and the framework it borrows from. `CALIBRATION.md` is the standing test of that, and it can fail
- **Not that the vocabulary is sufficient.** The first domain profile found six terms it could not carry, five of them landing on the coordinate the framework treats as primary
- **Not a standard.** Not a certification body, not an accreditation authority, not a court
- **Not an ecosystem.** 1 qualifying project and 1 steward. **A registry with one project in it is a format, not a commons**
- **Not proven operable by anyone else.** The runbook exists; nobody but the founder has followed it
- **Not durable.** No independent implementation, no second registry operator, no external security review
