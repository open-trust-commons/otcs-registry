# Objection 001 — the seed registry is founder-only

**Raised:** 2026-07-25 (self-raised; recorded as a material objection so the
first external reader finds it already on the record).

**Objection.** Every registered record is founder-maintained. A registry
launched this way could read as self-promotion wearing governance clothing —
the exact pattern EVIDENCE-MODEL.md §7 says this system prevents.

**Answer (2026-07-25).** The condition is real and is mitigated by structure
rather than denial: (1) record_state discipline — nothing here is observed or
implied third-party participation; (2) every founder record carries independent
validation 0, stated; (3) relationship edges among founder projects are marked
self_asserted with the founder edge named in asserted_by; (4) each record's
`needs` field openly solicits the external evaluation that would change those
scores; (5) CHARTER.md §6 declares the conflict, §7 defines the exit from
founder governance. The registry's founder-only state is disclosed as a stage,
not laundered as an ecosystem.

**Status:** answered; carried on the record.
